# 📈 Zerodha Clone

A full-stack clone of the Zerodha trading platform built for learning and practicing modern web development concepts.

The project recreates key parts of a stock trading platform, including a landing website, user dashboard, portfolio interface, holdings, positions, and order-related UI.

> **Note:** This is an educational project and is not affiliated with or endorsed by Zerodha.

---

## 🚀 Features

- Responsive Zerodha-inspired landing page
- User dashboard interface
- Holdings and positions sections
- Orders interface
- Portfolio overview
- Clean and responsive UI
- Frontend and backend separation
- REST API integration
- Database integration

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

```bash
cd Zerodha-CLONE
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
npm start
```

### 4. Install Dashboard Dependencies

Open another terminal:

```bash
cd dashboard
npm install
npm start
```

### 5. Install Backend Dependencies

Open another terminal:

```bash
cd backend
npm install
```

Start the backend using the script configured in `backend/package.json`.
